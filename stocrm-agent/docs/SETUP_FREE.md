# Бесплатные провайдеры и лимиты (дополнение к инструкции)

**Пошаговая установка с нуля — в [INSTALL.md](INSTALL.md).** Здесь подробнее про то, где брать
бесплатные ключи, какие у них лимиты и чем заменить, если чего-то не хватает.

Платить не нужно ни за что: работаем на своём компьютере, ключи берём на бесплатных тарифах.

Если что-то пошло не так — не читайте всю инструкцию заново, посмотрите раздел
[«Если не работает»](#если-не-работает) в конце.

---

## Что мы собираем

```
Вы говорите голосовое в Telegram
        ↓
Telegram-бот на вашем компьютере  ──►  распознаёт речь (Whisper, бесплатно)
        ↓
   LLM понимает, что вы просите  ──►  находит сделку, услугу, запчасть
        ↓
   Показывает ЧЕРНОВИК: «внести вот это?»  ──►  вы жмёте «Применить»
        ↓
              Ваша панель STOCRM
```

Ключевое правило: **ничего не записывается в CRM без вашего подтверждения**. Это можно
ослабить или усилить в `/settings` внутри бота.

## Что бесплатно, а что нет

| Что нужно | Сколько стоит | Где берём |
|---|---|---|
| Панель STOCRM | у вас уже есть (подписка на CRM) | ваш домен `что-то.stocrm.ru` |
| Ключ STOCRM (SID) | **бесплатно**, входит в подписку | панель → Настройки → API Ключи |
| Telegram-бот | **бесплатно** | @BotFather в Telegram |
| «Мозг» агента (LLM) | **бесплатно** на лимитах Google | aistudio.google.com/apikey |
| Распознавание речи (Whisper) | **бесплатно** на лимитах Groq | console.groq.com |
| Компьютер, интернет | у вас уже есть | — |
| Хостинг 24/7 | **бесплатно на своём ПК** (он должен быть включён) | — |

Платить имеет смысл только позже, если захотите, чтобы бот работал круглосуточно без
включённого компьютера (это уже платный VPS, 200–400 ₽/мес). Для старта не нужно.

## Шаг 1. Установить Python

1. Откройте <https://www.python.org/downloads/> и нажмите большую жёлтую кнопку
   **Download Python 3.x**.
2. Запустите скачанный файл.
3. **Самое важное:** на первом экране поставьте галочку **«Add python.exe to PATH»** (внизу).
   Без неё ничего не заработает.
4. Нажмите **Install Now**, дождитесь окончания, закройте.

Проверка. Нажмите `Win + R`, введите `cmd`, Enter. В чёрном окне напишите:

```
python --version
```

Должно ответить что-то вроде `Python 3.12.4`. Если пишет `Python не является внутренней или
внешней командой` — значит галочку в пункте 3 не поставили: переустановите Python, выбрав
**Modify → Add Python to environment variables**.

> На macOS: `python3 --version`. Если питона нет — поставьте с того же сайта или через
> `brew install python`.

## Шаг 2. Распаковать проект и установить зависимости

1. Папку `stocrm-agent` положите в удобное место, например `C:\stocrm-agent`
   (или `Документы\stocrm-agent`). Внутри должны лежать `requirements.txt`, `stocrm_agent`, `docs`.
2. Откройте эту папку в проводнике, щёлкните по адресной строке, напишите `cmd` и нажмите Enter —
   откроется чёрное окно **уже в нужной папке**.
3. Выполните по очереди три команды:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

После второй команды слева появится `(.venv)`. После третьей — побегут строки `Collecting…`,
это нормально, ждём 1–2 минуты.

> **Если Windows пишет «выполнение сценариев отключено в этой системе»** — выполните
> `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`, ответьте `Y` и повторите
> `.venv\Scripts\activate`.
>
> **macOS / Linux:** вместо второй команды `source .venv/bin/activate`.

Проверка: `python -c "import aiogram, mcp, httpx; print('ok')"` → должно напечатать `ok`.

> Все следующие команды выполняются **в этом же окне** (там, где слева `(.venv)`).
> Закрыли окно — при следующем запуске снова `.venv\Scripts\activate`.

## Шаг 3. Взять ключ STOCRM (SID)

1. Откройте свою панель в браузере. Адрес выглядит так:
   `https://мойсервис.stocrm.ru` — запомните слово **мойсервис**. Это ваш «домен» для `.env`
   (без `https://`, без `.stocrm.ru`).
2. В панели: **Настройки → API Ключи → «Добавить API Ключ»**.
3. Дайте ключу имя, например `AI-агент`, сохраните и **скопируйте SID** — он выглядит как
   `123_abc456def…`. Он показывается один раз; если потеряли — создайте новый, старый удалите.
4. Убедитесь, что у ключа есть доступ к сделкам, работам, товарам, складам, сотрудникам
   (обычно достаточно прав владельца/администратора).

Проверить можно так (после шага 6, когда впишете ключ в `.env`):

```
python -m stocrm_agent.cli boards
```

Покажет список ваших воронок в виде JSON — значит ключ живой.

## Шаг 4. Создать Telegram-бота

1. В Telegram найдите **@BotFather** (синяя галочка), нажмите **Start**.
2. Отправьте `/newbot`.
3. Введите имя бота (как его увидят люди), например `Автосервис ассистент`.
4. Введите username — должен заканчиваться на `bot`, например `moy_servis_bot`.
5. BotFather пришлёт строку вида
   `7123456789:AAHq7x...` — **это токен**. Скопируйте целиком, никому не отправляйте.

Второй бот — чтобы узнать **свой ID**:

6. Найдите **@userinfobot**, нажмите Start. Он ответит: `Id: 123456789`. Запишите это число.

Этот ID нужен, чтобы ботом пользовались только вы и ваши сотрудники, а не случайные люди.

## Шаг 5. Взять бесплатные ключи: мозг на Google AI Studio, речь на Groq

Ключа нужно два, оба бесплатные и без карты. Они от разных сервисов и не мешают друг другу:
Google думает и понимает смысл, Groq расшифровывает голос.

### 5.1. Мозг агента — Google AI Studio (Gemini)

1. Откройте <https://aistudio.google.com/apikey>, войдите в обычный Google-аккаунт.
2. Нажмите **Create API key / Get API key** → **Create key in new project** (согласитесь с условиями).
3. Скопируйте ключ — он начинается на `AIza...`. Он бесплатный, карта не нужна.

Что важно знать про бесплатный тариф Gemini:

| Что | Как есть на октябрь 2026 |
|---|---|
| Бесплатные модели | `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.6-flash`, `gemini-3.8-flash`, `gemini-2.5-flash` |
| Лимиты | примерно **500 запросов в сутки** у Flash-Lite и **около 20** у Flash. Точные цифры видны в AI Studio → Rate limits |
| Карта | не нужна |
| Приватность | на бесплатном тарифе Google может использовать запросы для обучения — не отправляйте туда лишнего (паспорта, телефоны клиентов) |
| Обновления | Google регулярно меняет список моделей; актуальный смотрите в AI Studio → Models |

Почему по умолчанию **Flash-Lite**: у обычного Flash всего ~20 запросов в сутки, а один диалог
с агентом — это 2–4 запроса. Flash-Lite даёт ~500 и с инструментами справляется.
Если запросов стало мало — переключитесь на `gemini-3.8-flash` и следите за лимитом.

> С 28 мая 2026 новые ключи AI Studio выдаются как «auth keys» и работают только с Gemini API.
> Наш бот как раз обращается к Gemini API, так что всё совместимо.

### 5.2. Распознавание речи — Groq (Whisper)

У Gemini нет OpenAI-совместимого метода расшифровки аудио, поэтому голос оставляем на Groq —
это бесплатно и очень быстро.

1. Откройте <https://console.groq.com>, зарегистрируйтесь (можно через Google).
2. **API Keys → Create API Key**, имя любое → **Submit**.
3. Скопируйте ключ `gsk_...` (показывается один раз).
4. Лимиты бесплатного тарифа: ~20 запросов в минуту, ~2000 в сутки, около **8 часов аудио в сутки**.
   Для голосовых сообщений менеджеров этого с запасом.

<details>
<summary>Если хочется вообще без облака для голоса</summary>

Распознавание можно считать локально — бесплатно, приватно, без ключей:

```bash
pip install faster-whisper
```
```ini
STT_PROVIDER=local
STT_LOCAL_MODEL=small
```

Минус: модель (~500 МБ – 2 ГБ) скачивается при первом голосовом, и на слабом ноутбуке
расшифровка занимает несколько секунд вместо одной.
</details>

<details>
<summary>Другие варианты для мозга (если Google не подойдёт)</summary>

| Провайдер | Что вписать | Плюсы / минусы |
|---|---|---|
| Groq | `LLM_PROVIDER=groq` + `LLM_API_KEY=gsk_...` | тот же ключ, что для речи; модели `openai/gpt-oss-120b`; лимит ~2000 запросов/сутки |
| OpenAI | `LLM_PROVIDER=openai` + `LLM_API_KEY=sk-...` | платно, но предсказуемо и приватно (данные не в обучении) |
| DeepSeek | `LLM_PROVIDER=deepseek` + свой ключ | дешёвый, но пополнение счёта |
| Свой сервер (Ollama, vLLM, LM Studio) | `LLM_PROVIDER=custom` + `LLM_BASE_URL=http://localhost:11434/v1` + `LLM_MODEL=...` | полностью локально и бесплатно, нужен мощный ПК |

Адрес и модель подставляются автоматически по `LLM_PROVIDER`. Если впишете ещё и
`LLM_BASE_URL`/`LLM_MODEL` — они главнее пресета.
</details>

## Шаг 6. Вписать всё в файл `.env`

Это единственный файл, куда вводятся ключи. Лежит в корне папки `stocrm-agent`, рядом с
`requirements.txt`.

1. Сделайте копию шаблона. В том же чёрном окне:

```
copy .env.example .env
```

> macOS/Linux: `cp .env.example .env`

2. Откройте `.env` блокнотом: `notepad .env` (или `open -e .env` на macOS).

3. Замените значения на свои. Ниже — **минимальный набор для бесплатного запуска**.
   Строки, которые не упомянуты, трогать не нужно — там уже правильные умолчания.

```ini
# ─── STOCRM ───
STOCRM_DOMAIN=мойсервис
STOCRM_SID=123_abc456def

# ─── TELEGRAM ───
TG_BOT_TOKEN=7123456789:AAHq7x...
TG_ALLOWED_USERS=123456789
TG_ADMIN_USERS=123456789

# ─── LLM, «мозг» агента — Google AI Studio (бесплатно) ───
LLM_PROVIDER=google
LLM_API_KEY=AIza...вашключ
LLM_MODEL=gemini-3.5-flash-lite

# ─── РАСПОЗНАВАНИЕ РЕЧИ — Groq (бесплатно) ───
STT_PROVIDER=groq
STT_API_KEY=gsk_вашключ
STT_LANGUAGE=ru

# ─── Подтверждения: 1 = спрашивать перед каждой записью ───
TG_CONFIRM_REQUIRED=1
```

Правила, чтобы не спотыкаться:

- **Без кавычек** вокруг значений, без пробелов вокруг `=`.
- `STOCRM_DOMAIN` — только слово-префикс: `мойсервис`, а не `https://мойсервис.stocrm.ru/`.
- `TG_ALLOWED_USERS` — ваш числовой ID из шага 4. Несколько человек — через запятую.
  Оставьте пустым только для быстрого теста: тогда бот ответит любому, кто его найдёт.
- Файл `.env` **никому не отправляйте** и не выкладывайте: это полный доступ к CRM.
- Сохранить в блокноте: `Ctrl+S`, закрыть.
- Файл `.env` подхватывается сам при запуске — экспортировать переменные вручную не нужно.
  (Если положили его в другое место — укажите путь: `STOCRM_ENV_FILE=C:\путь\.env`.)

### Если какая-то модель недоступна

Модели на бесплатных тарифах меняются. Ошибка про модель (`404`, `model not found`) — откройте
<https://aistudio.google.com/apikey> → **Models**, возьмите ID любой бесплатной модели
Flash/Flash-Lite и впишите в `LLM_MODEL` (без префикса `models/`).

Для распознавания подойдёт `whisper-large-v3` или быстрый `whisper-large-v3-turbo`
(<https://console.groq.com/docs/models>).

`LLM_PROVIDER=google` — это подсказка, откуда брать адрес и модель. Можно вообще не использовать
пресеты и задать `LLM_BASE_URL` + `LLM_MODEL` вручную: подойдёт любой OpenAI-совместимый сервер.

## Шаг 7. Проверка одной командой

```
python -m stocrm_agent.cli doctor
```

Он по очереди проверит Python, библиотеки, файл `.env`, ключ STOCRM, LLM, распознавание речи,
токен Telegram и папку для данных. Хороший результат выглядит так:

```
✅ Python — 3.12.4
✅ Зависимости — mcp, requests, aiogram, httpx на месте
✅ Файл .env — C:\stocrm-agent\.env (переменных: 24)
✅ STOCRM — ключ работает, воронок: 3
✅ Папка состояния — C:\stocrm-agent\.state
✅ Telegram-бот — @moy_servis_bot
✅ LLM (мозг агента) — google: gemini-3.5-flash-lite ответил: 'ок'
✅ LLM: вызов инструментов — function calling работает (2 запроса)
✅ Распознавание речи — whisper-large-v3 принял тестовый файл (тишина)
```

Строка **«LLM: вызов инструментов»** — самая важная: она проверяет, что модель реально умеет
вызывать функции, через которые агент читает и пишет CRM. `➖` в этой строке значит, что модель
ответила текстом без вызова инструмента — с такой моделью бот будет «разговаривать», но ничего
не сделает. Возьмите другую модель (для Gemini это Flash-Lite и Flash, для Groq — `gpt-oss-*`).

Если где-то ❌ — под строкой есть подсказка `↳` с тем, что именно поправить. Исправили,
сохранили `.env`, запустили `doctor` снова.

Ещё одна проверка — **без CRM и без ключей**, на фейковых данных (полезно, чтобы понять, как
выглядит работа):

```
python -m stocrm_agent.cli demo
```

Должны увидеть список воронок, черновик и строку `applied`.

## Шаг 8. Запуск бота

```
python -m stocrm_agent.bot
```

В окне появится `Run polling for bot @moy_servis_bot` — бот работает. Окно **не закрывайте**:
пока оно открыто, бот жив. Остановить — `Ctrl+C`.

Теперь в Telegram:

1. Найдите своего бота по username, нажмите **Start** (`/start`).
2. `/staff` — бот покажет сотрудников из CRM (проверка, что связь есть).
3. Надиктуйте голосовое, например: *«В сделке Иванов, добавь замену масла, исполнитель Сергей,
   и масло 5W30 два литра»*.
4. Бот покажет: расшифровку → что понял → **черновик**. Ничего ещё не записано.
5. Нажмите кнопку **✅ Применить** — только теперь данные уйдут в STOCRM.
   Если бот не угадал — **❌ Отменить** и переформулируйте.
6. Если исполнитель не назван, бот предложит выбрать из списка сотрудников. Если вы ответите
   «без исполнителя», он обязательно переспросит: *«Точно никого не назначать?»* — потому что
   такая работа не попадёт в выработку.

Полезные команды в боте:

| Команда | Что делает |
|---|---|
| `/start` | краткая памятка |
| `/settings` | какие действия подтверждать (вкладки: сделки, работы, запчасти, контакты, задачи, заметки) |
| `/staff` | список сотрудников-исполнителей |
| `/drafts` | черновики, которые ждут вашего решения |
| `/reset` | забыть контекст разговора |

## Шаг 9. Запуск в один клик (необязательно)

Чтобы не открывать каждый раз терминал, в папке уже лежит `start_bot.bat` (Windows) —
достаточно двойного щелчка. На macOS/Linux используйте `./start_bot.sh`.

Если нужно, чтобы бот работал всегда: компьютер должен быть включён и не уходить в сон
(Параметры → Система → Питание → «Переход в спящий режим: Никогда»). Автозапуск при входе в
систему: `Win + R` → `shell:startup` → положить туда ярлык на `start_bot.bat`.

## Если не работает

| Что видите | В чём дело | Что сделать |
|---|---|---|
| `python не является внутренней…` | Python не в PATH | Переустановить Python с галочкой **Add python.exe to PATH** |
| `выполнение сценариев отключено` | Политика PowerShell | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` |
| `(.venv)` не появилось | Не активировали окружение | `.venv\Scripts\activate` в папке проекта |
| `Не задан TG_BOT_TOKEN` | `.env` не найден или пустой токен | Проверить, что файл называется ровно `.env` (не `.env.txt`), лежит в папке проекта; запустить `doctor` |
| `Файл .env не найден` в doctor | То же | `copy .env.example .env` и заполнить |
| `HTTP 401` / `Ключ неверный` (STOCRM) | Опечатка в SID или ключ удалён | Создать новый ключ, вставить целиком |
| `redirect` (STOCRM) | Домен указан с `https://` или `.stocrm.ru` | Оставить только префикс: `мойсервис` |
| `HTTP 400` «Please pass a valid API key» (Gemini) | Ключ Google скопирован не полностью или это ключ из другого проекта | Создать новый на aistudio.google.com/apikey |
| `HTTP 403` (Gemini) | Модель платная или закрыта для вашего проекта | Взять Flash-Lite/Flash из списка бесплатных в AI Studio |
| `HTTP 404` про модель (Gemini) | Такой модели нет | ID без `models/`, например `gemini-3.5-flash-lite` |
| `➖ LLM: вызов инструментов` | Модель без function calling или отключена | Выбрать другую модель; для Gemini — Flash или Flash-Lite |
| `HTTP 401` (LLM/STT) | Ключ вставлен не полностью | Скопировать `AIza...` / `gsk_...` заново |
| `HTTP 404` про модель | Модель убрали с бесплатного тарифа | Взять актуальную в console.groq.com/docs/models |
| `HTTP 429` | Превышен бесплатный лимит | Подождать минуту или до суток. У Gemini лимит на проект (20–500 запросов/сутки), у Groq — на аккаунт. Уменьшите `LLM_MAX_STEPS` до 4 |
| Бот стал медленнее отвечать | Gemini «думает» перед ответом | Нормально; можно поставить `LLM_REASONING_EFFORT=low` |
| `Речь не распознана` | Тишина/шум/слишком короткая запись | Записать 5–30 секунд внятной речи |
| Бот молчит в Telegram | Ваш ID не в `TG_ALLOWED_USERS`, или бот не запущен | Вписать ID из @userinfobot, перезапустить бота |
| `Conflict: terminated by other getUpdates` | Запущено два экземпляра бота | Закрыть лишние окна, оставить одно |
| `⚠️ Файл больше 20 МБ` | Такой файл Telegram не отдаёт ботам | Записать короче или разбить на части |
| Текст в CRM попал не туда | LLM не угадал сделку | Всегда проверяйте черновик; отменяйте и уточняйте номер сделки в запросе |

## Безопасность — три правила

1. `.env` = пароль от CRM. Не отправляйте файл в мессенджеры, не выкладывайте на GitHub
   (не публикуйте его).
2. Всегда заполняйте `TG_ALLOWED_USERS` — иначе ботом сможет пользоваться любой, кто узнает
   его адрес.
3. Ключ STOCRM можно отозвать в любой момент: панель → Настройки → API Ключи → удалить.
   Тогда бот просто перестанет писать в CRM.
