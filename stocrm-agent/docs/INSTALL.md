# Установка — версия 79

## Telegram без терминала (Windows)

Полный порядок обновления и проверка позиции — в **[README.md](../README.md)**.

1. Остановите старую копию, распакуйте архив в новую папку.
2. При обновлении перенесите собственные `.env` и `.state`. Не переносите `.venv`.
3. Установите Python 3.12/3.13, если его нет (с отметкой Add python.exe to PATH).
4. Запустите двойным щелчком `setup.bat`, дождитесь установки.
5. Запустите `start_bot.bat`, оставьте окно открытым.
6. Проверьте на новой тестовой сделке согласно README. Не повторяйте partial.

Первая настройка: домен/ключ STOCRM, Telegram-токен и разрешённые Telegram ID, ключ Google AI Studio для модели, Groq для речи. Мастер записывает локальный `.env`; его нельзя отправлять другим. Для реальной панели STOCRM_MOCK=0. Подтверждения держите включёнными в /settings.

Диагностика без изменения CRM: двойной щелчок `collect_report.bat`. Перед отправкой диагностического файла проверьте его на личные сведения. В отчёте должна быть версия 79.

Настройка провайдеров: [SETUP_FREE.md](SETUP_FREE.md), [LLM.md](LLM.md). Актуальные условия и лимиты зависят от аккаунта провайдера.

## Linux/macOS

Запустите `bash setup.sh`, затем `bash start_bot.sh`. Для обновления также сохраните `.env` и `.state`. Нужен Python и доступ к внешним сервисам.

## MCP (дополнительно, не нужен для Telegram)

После установки окружения MCP-клиент запускает:

- executable: полный путь к `.venv/Scripts/python.exe` (Windows) или `.venv/bin/python` (Linux/macOS);
- arguments: `-m`, `stocrm_agent.server`;
- working directory: распакованная папка `stocrm-agent`.

Если клиент не умеет задавать рабочую папку, передайте настройки через его переменные окружения, включая STOCRM_DOMAIN, STOCRM_SID и абсолютный STOCRM_STATE_DIR. Не публикуйте такой конфиг. Все записи требуют применения подготовленного черновика; сначала человек проверяет его данные.
